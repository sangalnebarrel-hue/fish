# Catch & Steal a Fish 🐟

MVP Roblox-игры по диздоку «Steal a Fish»: ловишь рыбу, держишь её в аквариуме ради дохода и воруешь чужую. Рыба в ведре задыхается, поэтому любую добычу надо успеть донести до своего аквариума.

Название «Steal a Fish» в Roblox уже занято, поэтому рабочее название — **Catch & Steal a Fish** (рекомендация из диздока). Перед публикацией проверь его поиском в Roblox.

## Запуск

Проект собирается [Rojo](https://rojo.space). Карта процедурная, ассеты не нужны: игра стартует в пустом плейсе.

1. Поставь инструменты: `rokit install` (версии в `rokit.toml`).
2. Открой в Roblox Studio шаблон **Baseplate** (плита и точка спавна из шаблона удалятся сами при старте сервера).
3. Запусти `rojo serve` и подключись плагином Rojo в Studio.
4. Нажми **Play**.

Или собери файл плейса: `rojo build default.project.json -o game.rbxl` и открой его в Studio.

### Перед публикацией

- **Game Settings → Places → Max Players = 8**: на сервере 8 баз.
- **Game Settings → Security → Enable Studio Access to API Services**, чтобы проверять сохранения в Studio. Без доступа ProfileStore работает на заглушке и ничего не сохраняет.
- Создай геймпассы VIP, «×2 Деньги» и «Кислородный баллон» и впиши их ID в `Config.GamePassIds` (`src/shared/Config.luau`). Пока ID равен 0, пасс в игре не продаётся.
- Замени звуки в `Config.Sounds`: сейчас там встроенные звуки движка.
- Впиши свой UserId в `Config.AdminUserIds` для админ-ивентов на живых серверах.

## Что в MVP

Всё из раздела «MVP и план апдейтов» диздока:

- [x] Гавань, 8 баз, зоны Пирс, Озеро и Коралловый риф (с медузами, которые замедляют)
- [x] Рыбалка одной кнопкой с мини-игрой подсечки
- [x] Ведро, полоска кислорода над головой (видна всем), лужи-чекпоинты (+10 с, перезарядка 30 с), выбитое ведро
- [x] Аквариум с расширением до 10 мест, доход раз в секунду, сохранение (ProfileStore, автосейв раз в 60 с)
- [x] Кража (удержание 1,5 с), сачок-шлепок, замок базы (60 с, перезарядка 3 мин), тревога
- [x] 12 рыб, 3 размера (Малёк, Обычная, Крупная), 2 мутации (Золотая, Электрическая), индекс с наградами
- [x] Магазин удочек, вёдер, наживки, ласт и расширений аквариума
- [x] Геймпассы VIP, ×2 Деньги и Кислородный баллон
- [x] Ивенты Косяк (каждые 30 мин) и Шторм (каждые 45 мин, молнии, Электрическая мутация)

Защита от бросания игры: 5 минут защиты базы новичку, слот-сейф, офлайн-доход 50% до 4 часов, при выходе база и рыба уходят с сервера вместе с игроком.

Остальной контент диздока (20 рыб, 5 размеров, все мутации, зоны до Бездны, все удочки и вёдра, все геймпассы) уже описан в данных и включается флагами в `Config`:

```lua
Config.EnabledZones = { Pier = true, Lake = true, Reef = true }
Config.EnabledSizes = { Fry = true, Normal = true, Large = true }
Config.EnabledMutations = { Golden = true, Electric = true }
Config.MaxAquariumTier = 2
```

Чтобы открыть новую зону, нужно ещё построить её в `MapService`.

## Управление

| Действие | ПК | Телефон |
| --- | --- | --- |
| Закинуть / подсечь | C или клик | кнопка «Закинуть», тап по мини-игре |
| Шлёп сачком | F | кнопка «Шлёп» |
| Замок базы | L (на своей базе) | кнопка «Замок» |
| Украсть, поднять, продать, открыть ворота | E (удержание у чужого аквариума) | кнопка у объекта |

## Админ-команды

Работают в Studio, у создателя плейса и у игроков из `Config.AdminUserIds`:

```
/money 1e6                  деньги
/event shoal|storm [сек]    запустить ивент (админ-ивенты по выходным)
/stopevent shoal|storm
/give ChefOcto Large Golden рыба в аквариум
/unlock                     открыть все зоны
/reset                      сбросить свои данные (только Studio)
```

## Устройство

```
src/shared/     ReplicatedStorage.Shared — данные и формулы, общие для сервера и клиента
  Config        все настройки баланса и флаги MVP
  FishData      рыбы, редкости, размеры, мутации, зоны
  ShopData      удочки, вёдра, наживка, аквариум, геймпассы
  Formulas      чистая математика: броски улова, доход, кислород, скорость, цены
  FishModel     процедурные модели рыб из деталей
  Net           список RemoteEvent / RemoteFunction
src/server/     ServerScriptService.Server
  Services/     DataService, MapService, BaseService, BucketService, FishingService,
                EconomyService, EventService, ShopService, SlapService, MovementService,
                AntiCheatService, HazardService, MonetizationService, IndexService, ...
  Packages/     ProfileStore (Apache 2.0, лицензия в licenses/)
src/client/     StarterPlayerScripts.Client — HUD, мини-игра, панели, эффекты
tests/          юнит-тесты баланса и смоук-тест мира
```

Ключевые решения:

- **Всё, что стоит денег, считает сервер**: владение рыбой, доход, кислород, шансы улова, перезарядки. Клиент получает только редкость клюнувшей рыбы и параметры мини-игры.
- **Кража без дюпов**: украденная рыба остаётся в сохранении владельца с пометкой «в пути». Владелец меняется одним действием, когда вор доносит её до своего аквариума; после этого оба профиля сохраняются сразу.
- **Доход** начисляет один серверный цикл раз в секунду на всех игроков.
- **Кислород** считает сервер. Клиенту уходят атрибуты (запас, расход, отметка времени), полоску он рисует сам.
- **Ивенты** идут по мировым часам, поэтому на всех серверах начинаются одновременно.
- **Античит**: сервер проверяет дистанцию при краже (не дальше 8 студов) и время удержания, сверяет скорость игрока с его статом и откатывает телепорты и спидхак.
- **Аналитика**: улов, кражи, покупки и воронка новичка через AnalyticsService.

## Проверки

```
scripts/check.sh
```

Скрипт запускает StyLua, Selene, luau-lsp в strict-режиме с типами Roblox API, юнит-тесты баланса (`tests/run.py`, нужен `luau`) и три смоук-теста в [Lune](https://github.com/lune-org/lune). Lune исполняет собранный плейс с настоящими `script`/`game` и сверяет каждое свойство с базой Roblox API, а движковые методы и события подменяет заглушками (`tests/lune/runtime.luau`):

- `tests/world.lune.luau` строит карту и все 700 вариантов моделей рыб и проверяет геометрию: рыбы внутри аквариумов, вор дотягивается до любой рыбы, время бега до зон совпадает с диздоком (Пирс ≈ 4 с, Озеро ≈ 15 с, Риф ≈ 30 с с ведром);
- `tests/client.lune.luau` поднимает весь клиент в режимах телефона и ПК, открывает все панели и вкладки, проходит заброс → поклёвку → подсечку → улов, уведомления, тревогу и эффекты;
- `tests/server.lune.luau` запускает все сервисы, заводит двух игроков и проходит цикл диздока: рыбалка, кислород и фонтан, доставка, доход, кража, шлепок и подбор, перенос владения, сейф, магазин, рынок, ворота, наживка, ивенты, замок, выход вора с краденой рыбой.

## Что ещё не проверено

Код не запускался в самом Roblox Studio: он проверен статически и прогнан в Lune, где физика, рендер и сеть заменены заглушками. При первом запуске в Studio стоит посмотреть:

- ощущение мини-игры подсечки и физику отбрасывания от шлепка;
- интерфейс на телефоне (Device Emulator в Studio): размеры кнопок и что они не перекрывают джойстик;
- звуки: сейчас там встроенные `rbxasset://` звуки, их стоит заменить.
